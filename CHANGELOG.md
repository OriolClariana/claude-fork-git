# Changelog

## 1.0.0

First stable release.

- Git panel with Changes, History, Submodules and Stashes tabs.
- Stage, unstage, discard and commit with a draft that survives restarts.
- Fetch, pull (merge or rebase), push, branch create, rename and delete, stash.
- History with graph, search and scope filter.
- Live status orb, tiles and clean-state animation.
- Settings pane with 15 options, plus `/git`, `/git-settings` and `/git-close`.
